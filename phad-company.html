ให้ทีมใช้ Claude Code บนเครื่องของคุณ ทำงานแบบ agentic: ค้นเว็บจริง อ่าน เขียน และแก้ไฟล์ได้เอง จนภารกิจเสร็จ ผลงานเป็นไฟล์จะอยู่ในโฟลเดอร์ PHAD-Workspace บนเครื่องคุณ ใช้โควตาบัญชี Claude ของคุณ ไม่ใช้ Gemini

เริ่มใช้ครั้งแรก

  1. ติดตั้ง Node.js และ Claude Code แล้วล็อกอิน (พิมพ์ claude ใน terminal ได้)
  2. ดาวน์โหลด phad-bridge.js
  3. เปิด terminal ในโฟลเดอร์ที่ดาวน์โหลด แล้วรัน node phad-bridge.js
  4. นำ รหัสจับคู่ ที่ขึ้นใน terminal มาใส่ด้านล่าง แล้วกด "เชื่อมต่อ" (ถ้าเบราว์เซอร์ถามสิทธิ์เข้าถึงเครือข่ายภายใน ให้กดอนุญาต)

ทีมรันคำสั่ง shell ไม่ได้ (ค่าเริ่มต้น) ถ้าต้องการ ให้รันด้วย node phad-bridge.js --allow-bash · bridge รับงานเฉพาะจากหน้านี้และต้องมีรหัสจับคู่ · ปิด bridge ได้ด้วย Ctrl+C
